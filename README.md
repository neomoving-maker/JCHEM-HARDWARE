# JCHEM HARDWARE

제이켐 하드웨어의 KCC M500 주문접수 및 하드웨어 BOM 산출 웹페이지입니다.

- 창짝 타입, 벤트 방향, 댐퍼 옵션, 치수와 세트수량에 따른 부품 조회
- 핸들높이에 따른 기어·연결부 및 절단량 계산
- 엑셀 주문 가져오기, 부품별 통합 집계, CSV 발주서 및 PDF 인쇄

## 실행 및 배포

`index.html`을 브라우저에서 열면 실행됩니다. 기존 HTML의 내용은 그대로 유지하고 GitHub Pages의 시작 파일명으로 변경했습니다.

웹사이트: https://neomoving-maker.github.io/JCHEM-HARDWARE/

GitHub Pages는 `main` 브랜치의 루트 폴더에서 배포합니다. `index.html`을 수정하여 커밋하고 푸시하면 변경 내용이 배포됩니다.

입력한 주문은 브라우저 메모리에서 처리되므로 새로고침 전에 필요한 결과를 내보내세요.
